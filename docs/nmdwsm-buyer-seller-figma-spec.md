# NMDWSM 買家賣家流程重作 Figma 規格

## 目標

這份規格用來建立「一次買夠二手交易平台」的 Figma 設計稿，範圍包含買家、賣家與會員相關介面。視覺方向採用藍色科技電商，保留目前網站的深藍導覽、紅色價格、亮藍主要操作，並讓交易流程更接近正式電商平台。

## Components

### Header / Nav

- 左側品牌：一次買夠二手交易平台。
- 中間搜尋框：placeholder「搜尋商品...」。
- 右側：購物車、會員頭像、使用者名稱。
- 會員下拉：我的帳戶、購買清單、登出。
- 主導覽：首頁、商城、智慧推薦、討論區、市價查詢、賣家中心。

### Buttons

- Primary：藍底白字，用於「立即購買」、「送出訂單」、「新增商品」。
- Secondary：白底藍字，用於「查看商品」、「管理商品」。
- Danger：紅底白字，用於「取消訂單」。
- Disabled：灰底灰字，用於已完成或不可操作狀態。

### Cards

- Radius：16px。
- Border：`#dce6f1`。
- Shadow：`0 12 28 rgba(15, 23, 42, 0.08)`。
- 內距：20px 到 24px。

### Status Pills

- 待付款：藍色系。
- 待出貨：藍色系。
- 已完成：綠色系。
- 不成立：灰色系。
- 退貨 / 退款：灰色系。

## Screens

### 1. 商品詳情頁

目的：讓買家快速判斷是否購買二手零件。

主要區塊：

- 商品圖片大圖。
- 商品名稱、價格、分類、狀況、品牌、用途、瀏覽數。
- 主要操作：加入購物車、立即購買、收藏商品。
- 賣家資訊：賣家名稱、商品所在地或品牌，不顯示 email。
- 商品描述：使用狀況、配件、交易注意事項。
- 未來擴充：燒機驗證區塊顯示為「未來可接入」。

### 2. 購物車頁

目的：讓買家確認準備結帳的商品。

主要區塊：

- 商品列：圖片、名稱、賣家、單價、數量、小計。
- 金額摘要：商品總額、交易方式提示、前往結帳。
- 空狀態：目前購物車沒有商品。

### 3. 結帳頁

目的：展示下單前最後確認。

主要區塊：

- 訂單商品。
- 買家備註。
- 交易方式：面交測試 / 私訊聯絡，標註「展示用，不含金流物流」。
- 訂單摘要與送出訂單。

### 4. 購買清單頁

目的：買家查看交易紀錄。

主要區塊：

- 狀態分頁：全部、待付款、待出貨、已完成、不成立、退貨 / 退款。
- 訂單卡片：訂單編號、建立時間、狀態、圖片、商品、賣家、單價、數量、總價。
- 操作：查看商品、取消訂單。
- 空狀態：目前沒有購買紀錄。

### 5. 會員中心頁

目的：整合帳戶資料與買家活動摘要。

主要區塊：

- 帳戶資料卡：使用者名稱、email、電話、城市。
- 購買摘要：待付款、已完成、收藏數。
- 收藏商品列表。
- 近期交易。

### 6. 賣家中心首頁

目的：展示賣家後台首頁。

主要區塊：

- 左側側邊欄：賣家首頁、我的銷售、我的商品、新增商品、市價查詢、智慧推薦、討論區。
- 訂單總覽：待處理訂單、已完成訂單、取消訂單、上架中商品。
- 賣家數據：成交金額、商品數、瀏覽數、訂單數、轉換率。
- 近期銷售。
- 營運表現、推薦給您、平台公告。

### 7. 商品管理頁

目的：賣家管理商品。

主要區塊：

- 狀態分頁：上架中、已售出、已下架。
- 商品列：圖片、名稱、分類、價格、狀況、瀏覽數、狀態。
- 操作：編輯、下架、查看商品。

### 8. 新增 / 編輯商品頁

目的：賣家新增或修改商品。

主要區塊：

- 商品表單：名稱、分類、價格、狀況、品牌、用途、數量、圖片網址、描述。
- 商品預覽：圖片、名稱、價格、描述、標籤。
- 操作：送出商品、取消。

### 9. 我的銷售頁

目的：賣家查看買家交易紀錄。

主要區塊：

- 訂單列表：買家、商品、狀態、建立時間、金額。
- 操作：查看商品。
- 本階段不做留言、付款、物流、確認出貨。

## User Flows

### 買家購買流程

1. 商城瀏覽商品。
2. 進入商品詳情。
3. 加入購物車或立即購買。
4. 購物車確認商品。
5. 結帳送出訂單。
6. 購買清單查看狀態。

### 賣家管理流程

1. 進入賣家中心。
2. 查看訂單與賣家數據。
3. 新增商品。
4. 到商品管理查看上架狀態。
5. 到我的銷售查看買家交易。

## 實作注意事項

- Figma 設計稿不承諾真實金流、物流、客服聊天與廣告投放。
- 燒機驗證只保留為未來擴充，不放入第一版核心交易流程。
- 後續 HTML/CSS 實作時可優先重作 `product.html`、`cart.html`、`checkout.html`、`transactions.html`、`account.html`、`seller.html`、`products.html`。
