跑分軟體使用方法

請依照以下步驟使用 OCCT 進行檢測，完成後將 log 貼回商品表單，系統會嘗試自動擷取分數。

1. 下載並安裝 OCCT

前往 OCCT 官方網站下載最新版本，安裝完成後開啟程式。

2. 選擇檢測項目

建議選擇 CPU 或 GPU 測試項目，讓 OCCT 產生完整測試結果。

3. 執行測試並儲存 log

完成測試後，將 OCCT 產生的 log 檔案儲存下來（通常為文字檔）。

4. 將 log 內容貼回本系統

打開 log 檔案，複製全部內容，回到「賣家中心」中的「跑分軟體檢測」欄位貼上。

本系統會嘗試從 log 中自動解析分數，例如包含「3DMark」或「CPU Test」相關結果時，會將分數存入商品資料庫，後續可用於定價模型。
若解析失敗，請確認已貼上完整 log 內容。
